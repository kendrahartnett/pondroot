# Bounded synthetic integration spike

This folder is excluded from Vercel uploads. It is not a public API or the production application floor. Only synthetic facts may be used.

The rules test is written before implementation. Record its behavioral red output, then implement validation without changing expectations. This small spike suite does not replace later authentication, ownership, persistence, browser, or user testing.

AI credentials come from process environment or the dedicated API-key entry in this project's ignored .env.local. The script never loads a reference project's environment, writes credentials, or prints provider error bodies. Use a dedicated capstone key and verified retention configuration before real-user processing.

PDF fixtures are synthetic, created through the candidate React PDF integration, and checked using extraction and page rendering. Local renderer success alone does not demonstrate mobile download or browser attachment usability.
